01

当前全貌

先按真实顺序把入口摆出来。标注「Engram」的是自研项；其余是 Vditor 内置项（图标与行为沿用 Vditor）。 手机端不是桌面端的等比缩小：桌面 20 个按钮，手机只保留 12 个，表格 / 代码 / 引用 / 待办 / 分割线收进「插入」底部面板。

桌面工具栏20 个按钮 · 5 组分隔完整功能面

02

不好用的地方（先不改，等你拍板）

判定标准只有一条：正在写作的人会不会被卡住或绕路。P0 是「做不到 / 只能靠手打语法」，P1 是「做得到但绕、或两端不一致」，P2 是「能用，但不够顺手」。

P0 功能缺口：没有入口，只能手打或绕路
F01

桌面端没有「插入图片」入口 P0

桌面工具栏没有上传项，只能靠粘贴、拖拽或先复制图片文件再粘贴；想从磁盘挑一张图插进正文，没有可点的入口。

手机端反而有「插入 → 图片」，两端能力倒挂。

建议：桌面工具栏补一个插入组（图片 / 文件 / 表格），复用手机插入面板的上传接口；或把手机「插入」面板提升为两端共用的插入菜单。

F02

桌面端不能删除整张表格 P0

表格浮条的「更多」在桌面被 display:none 隐藏，openTableMore() 又只在手机档响应；桌面上唯一的删表方式是逐列删除，直到最后一列把整表带走。

这是一个「知道的人不敢点、不知道的人找不到」的破坏性操作。

建议：桌面也提供「删除整张表格」，放进表格浮条或右键菜单（带确认/撤销提示）。

F03

插入表格固定 2×2，没有列数 / 对齐 / 表头选项 P0

工具栏「表格」直接插入 | 列 1 | 列 2 | 的 2×2 空表；不能选行列数，不能设对齐，不能切换表头行，也不能把首行改成普通行。

真实资料经常是 3×5、4×6；用户插入后第一件事就是反复点「插入列 / 插入行」。

建议：插入时给一个 8×8 网格选择器；表格浮条补对齐（左/中/右）与表头开关；「更多」补转置、CSV 粘贴。

F04

代码块没有语言选择 P0

工具栏「代码块」插入的是空围栏 ```，没有语言下拉；手机插入面板同样只插空围栏。用户必须自己记得写 ```ts 或 ```python，否则高亮和后续 AI 判断都缺依据。

Vditor 的语言提示只会在输入围栏后出现，入口本身没有引导。

建议：插入时先弹出常用语言（TS / JS / Python / SQL / JSON / Bash / Mermaid…），或插入后自动聚焦语言位并给候选。

F05

桌面端没有「高亮」入口 P0

高亮只出现在手机选中浮条（==），桌面工具栏和右键菜单都没有。桌面用户高亮一句话，只能手动在两侧敲 ==。

知识库做摘录/重点标记时，高亮是高频动作，比删除线更常用。

建议：桌面工具栏补高亮按钮；或在右键菜单补一组「格式」子菜单（高亮 / 行内代码 / 清除格式）。

F06

公式没有入口（KaTeX / MathJax 已随包） P0

仓库把 Vditor 整份 dist 随包拷贝，js/katex 与 js/mathjax 本来就能渲染公式；但工具栏没有行内公式 / 块级公式按钮，也没有符号面板，用户只能记住 $...$ 与 $$...$$。

这是「渲染能力已经在，入口没接」的典型浪费。

建议：补「行内公式 / 块级公式」两个入口，插入后用 KaTeX 预览；再给一个常用符号面板（希腊字母、上下标、矩阵、求和）。

F07

流程图 / 图表没有入口（Mermaid 等已随包） P0

Vditor 的 js/mermaid、js/flowchart.js、js/echarts、js/graphviz 都随包拷贝（web/vite.config.ts 的注释明确列出），但工具栏没有「流程图 / 图表」入口，也没有模板。

用户要画流程，只能凭空写出 ```mermaid 加整段语法；写错一个缩进就整块不渲染。

建议：插入面板加「图表」组：流程图（Mermaid）、简单流程（flowchart.js）、数据图（ECharts）、关系图（Graphviz），每个给一段可改的模板，并提示渲染器已内置。

F08

画板 / 白板完全没有 P0

没有 Excalidraw / tldraw / draw.io 之类的画布，也没有「把画板存成页面资产再插回正文」的链路。想画草图只能外部截图再上传。

这是你明确点名的扩展方向，也是知识库里「流程图之外的草图/架构图」最自然的位置。

建议：先做「画板 → 导出 SVG/PNG + 源文件 → 存页面资产 → 插入图片并保留可再编辑的源文件链接」；不要一上来做整页白板。

F09

没有目录块（TOC）入口 P0

桌面上有「大纲」按钮（Vditor 的侧栏目录），但正文里不能插入一个随标题更新的 [toc] 目录块；手机端的目录藏在「格式」二级面板里，还要先打开开关。

长文分享/阅读时，正文目录比侧栏大纲更直观。

建议：插入面板 / 工具栏加「目录块」，写入 [toc]；手机「格式」面板保留现有大纲开关，两者共用同一份标题解析。

F10

没有脚注入口 P0

GFM 脚注（[^1]）在预览里能渲染，但工具栏没有「插入脚注」，也没有脚注列表的管理视图；用户必须自己编号、自己写文末定义。

知识库引用来源时，脚注比正文括号更干净。

建议：插入时自动取下一个可用编号，在文末补定义；点击脚注标记可跳到定义（Vditor 预览已支持锚点）。

F11

没有提示块 / Callout P0

没有 > [!note] 这类提示块语法，也没有对应的渲染样式。重要提醒只能写成普通引用，和正文引用混在一起。

知识库里的「注意 / 警告 / 结论」需要视觉分层，这对阅读效率的提升非常直接。

建议：先支持 GitHub Alerts 语法（note / tip / important / warning / caution），补一套与暖纸主题一致的样式；入口放在插入面板。

F12

图片没有尺寸 / 对齐 / 图注控制 P0

插图后只有 ![alt](url)，不能拖拽改宽、不能居中对齐、不能写图注，也不能把一组图排成画廊。

知识库里的截图、架构图、对比图经常需要控制宽度；现在只能外部先裁好再上传。

建议：选中图片时浮出一个小工具条（宽度 25/50/75/100%、对齐、图注）；底层用 HTML 属性或自定义 Markdown 扩展，渲染时统一处理。

P1 高频但绕：做得成，路径不顺
F13

手机工具栏 12 个按钮单行横滚，末端入口靠猜 P1

390–412px 视口放不下 12 个 44px 按钮，工具栏只能横滚；滚动条隐藏，只靠右侧渐隐提示「还能滑」。AI 和「插入」正好在末端。

用户第一次用时不知道右边还有按钮；最需要的「插入」反而最难发现。

建议：工具栏固定保留「插入 / AI」在首屏，低频项收进「更多」托盘；或用分组标签（格式 / 块 / 插入）替代一条长龙。

F14

手机端没有「重做」 P1

手机工具栏只有撤销，没有重做；桌面有重做。误撤销后，手机上只能再手动写一遍。

触屏误触概率更高，重做的价值比桌面更大。

建议：手机工具栏补重做（可与撤销合成一个分段按钮），或放进「更多」。

F15

选中浮条不能把整段改成标题 / 列表 / 待办 P1

选中一段文字后，浮条只有加粗/斜体/高亮/链接/复制/更多；「更多」里是删除线/行内代码/引用/复制/全选。想把这段变成 H2、无序列表或待办，必须先取消选择，再把光标放进去用顶部工具栏。

「选中 → 改成标题」是移动端最自然的操作，现在被拆成两步且丢选区。

建议：浮条「更多」补标题（H1–H3）、无序/有序/待办；或者把「更多」升级成完整的格式面板。

F16

标题菜单只有 H1–H6，没有「正文」 P1

Vditor 的标题下拉是 H1–H6，没有「正文 / 清除标题」；取消一个标题只能手动删掉行首的 #。

手机上定位到行首删 # 很别扭；而且用户不一定知道标题在源码里就是 #。

建议：下拉末尾加「正文」，执行清除标题；同时显示当前标题级别。

F17

手机「插入」面板与桌面工具栏动作重复但形态不同 P1

手机把表格/代码/引用/待办/分割线收进「插入」面板；桌面把这些直接摆在工具栏，且没有「插入」总入口。两端对同一个动作的路径不一致。

用户换端后要重新记一遍入口；功能演进也容易只改一端。

建议：把「插入」做成两端共用的统一面板（图片 / 文件 / 表格 / 代码 / 引用 / 待办 / 分割线 / 图表 / 公式），桌面工具栏只留高频项。

F18

「链接」和「双链」相邻、同一种图标语言 P1

手机工具栏里 link 和 wikilink 紧挨着，都是链形图标；触屏没有 hover tooltip，用户分不清哪个是外部链接、哪个是 [[双链]]。

双链是 Engram 的核心能力，混在普通链接旁边反而被稀释。

建议：双链换成更有辨识度的图标（如双方括号/节点连线），并和普通链接拉开分组；首次使用时给一句说明。

F19

手机目录藏在二级面板，源码模式还跳不了 P1

目录入口在页头「格式」面板里，要先打开面板、再打开目录开关；切到源码模式后，点目录项会提示「暂不支持按目录跳转」。

目录是长文导航，入口层级太深；源码模式下的能力断点没有替代方案。

建议：源码模式按 Markdown 行号定位标题，或至少把目录入口提到页头一级；不要让「切到源码」等于「失去大纲」。

F20

表格浮条在窄屏可能压住表头，桌面没有「更多」 P1

浮条贴在表格上方，表格上半部分滚出视野时改贴光标行；窄屏上浮条本身可横滚，仍可能盖住第一行。桌面端没有「更多」，整表操作缺失（见 F02）。

表格操作本身高频，浮条一挡就看不清正在改哪一行。

建议：浮条改为贴表格右上角/下方，或压缩成「行 / 列 / 更多」三个入口；桌面与手机共用同一套整表操作。

F21

没有查找 / 替换 P1

长页面里找一个词只能靠浏览器查找（会跳出编辑器语义），替换更是完全手工。

整理长文、统一术语时，替换是刚需。

建议：加 Ctrl+F 的页内查找条（高亮匹配、上下跳转），替换做成可折叠的第二步；只作用于当前正文，不跨页。

F22

没有「清除格式 / 转为正文」 P1

从网页/Word 粘贴进来的加粗、链接、标题层级经常是脏的；工具栏没有一键清除，只能逐项反向操作。

「粘贴后先清格式再重排」是知识库录入的常见路径。

建议：右键菜单或选中浮条加「清除格式」：去掉行内样式与标题/列表标记，保留纯文本与双链。

P2 体验细节：能用，但不够顺手
F23

工具栏不显示当前块状态 P2

光标在 H2、列表、引用里时，工具栏没有明确的级别/类型指示；用户点「标题」前不知道当前是哪一级。

建议：标题下拉显示当前级别（如「H2 ▾」）；列表/引用按钮用 active 态标出，和 Vditor 的 vditor-menu--current 对齐。

F24

没有快捷键速查 P2

只有 placeholder 提到 [[ 和 Ctrl+S；加粗、标题、列表、双链候选、保存等快捷键没有入口可查。

建议：加一个「?」按钮/菜单项，弹出快捷键表；以后新增 AI / 图表快捷键也往这里收。

F25

没有「粘贴为纯文本 / 粘贴链接到选中文字」 P2

粘贴带格式内容时只能事后清理；选中文字再粘贴 URL 也不会自动变成链接。

建议：右键菜单补「粘贴为纯文本」；选中文字时粘贴 URL 自动包成 [选中文字](url)。

F26

没有分栏预览 P2

只有「即时渲染 / 源码」两态和只读的沉浸阅读；想一边写源码一边看渲染结果，没有分栏。

建议：在源码模式加一个可选的右侧预览（复用 Vditor 的预览渲染），窄屏自动收起。

F27

「即时渲染 / 源码」没有解释 P2

编辑模式下拉隐藏了 wysiwyg，只留两项，但没有一句话说明两者差异；新用户不知道什么时候该切源码。

建议：下拉项加副标题（「即时渲染：所见即所得」「源码：直接改 Markdown」），或在首次切换时给一次提示。

F28

按钮反馈不统一 P2

有的按钮有 active 态（部分 Vditor 项），有的没有；点完「表格」「代码块」后没有插入位置的轻提示或光标定位说明。

建议：统一 active 态与插入后光标落点（表格落到第一个单元格、代码块落到围栏内、公式落到 $ 之间）。

03

值得加的扩展（含你点名的流程图 / 画板）

「渲染器已随包」不是猜的：web/vite.config.ts 明确把 Vditor 整份 dist 拷进产物，注释列出的按需渲染器包括 mermaid、katex/mathjax、echarts、graphviz、flowchart.js、abcjs 等。也就是说，图表类功能缺的是入口与模板，不是渲染能力。 工作量按 S（1–2 天）/ M（3–5 天）/ L（1–2 周+）估。

Mermaid 流程图 / 时序图 / 状态图 / ER / 甘特 S

最值得先做的一项。Mermaid 覆盖你点名的「画流程图」，同一套语法还能画时序图、状态图、ER 图、甘特图和饼图。

渲染器已随包插入模板 + 语言选择

入口：插入 → 图表 → 流程图；选「流程 / 时序 / 状态 / ER / 甘特」后插入对应模板，光标落在第一行，旁边给「渲染预览」提示。

flowchart.js 简单流程 S

比 Mermaid 更轻的节点连线语法，适合「开始 → 判断 → 结束」这类小流程图。

渲染器已随包模板即可

入口：与 Mermaid 放在同一个「图表」组，作为第二种流程语法。

KaTeX / MathJax 公式 S

行内公式、块级公式、常用符号面板；仓库已经带 KaTeX 样式与渲染器，只差入口。

渲染器已随包符号面板可选

入口：工具栏「Σ」→ 行内 / 块级；选中文字后点行内公式可直接包起来。

ECharts 数据图 M

柱状图、折线图、饼图等；给一段 JSON option 模板，适合把一段数据变成图。

渲染器已随包JSON 模板 / 表单

入口：插入 → 图表 → 数据图；先给最简单的柱状图模板，避免一上来要求用户写完整 option。

Graphviz DOT 关系图 M

复杂依赖、组织关系、调用链；DOT 语法比 Mermaid 更适合大图。

渲染器已随包模板 + 语法提示

入口：插入 → 图表 → 关系图（Graphviz）。

Excalidraw 画板 L

你点名的「画板」。建议做成「页面内的画板资产」：画完导出 SVG/PNG 插入正文，同时把可编辑源文件存进页面资产。

需自研集成资产存储复用现有上传

入口：插入 → 画板；画板以弹窗/全屏打开，保存后插入图片，并保留「再次编辑」链接。不要先做整页白板。

draw.io / diagrams.net L

比 Excalidraw 更偏「正式架构图/UML」，可嵌入官方编辑器；同样建议走「导出 + 源文件资产」。

需 iframe / 外部服务离线端要降级

入口：与画板同组，作为第二种画布；离线不可用时只保留「上传图片」。

Markmap / 思维导图 M

把标题层级直接渲染成思维导图，适合知识树和方案拆解；是否随包需要确认 js/markmap 是否存在。

需确认随包模板 + 预览

入口：插入 → 图表 → 思维导图；也可以做「由当前标题生成导图」的一键动作。

PlantUML M

UML 时序/类图的老牌语法；Vditor 支持 plantuml 渲染，但通常需要外部渲染服务（Kroki 或 PlantUML Server）。

需外部渲染 / 服务端离线端降级

入口：插入 → 图表 → PlantUML；没有服务时提示改用 Mermaid。

ABC 乐谱 S

用 ABC 记谱写旋律；随包渲染器已有，属于低频但「知识库里有就用得上」的扩展。

渲染器已随包模板即可

入口：插入 → 图表 → 乐谱；只在用户明确需要时出现，不占主工具栏。

表格增强 M

8×8 行列选择器、表头开关、列对齐、转置、从 CSV/Excel 粘贴生成表格、表格内换行。

自研与现有表格浮条合并

入口：插入 → 表格（网格选择器）；表格浮条 → 对齐 / 表头 / 更多（转置、CSV、删除整表）。

代码块增强 M

语言选择、文件名标题、行号、复制按钮、diff 高亮；Mermaid 等图表语言可从同一入口进。

Vditor 配置 + 自研与插入面板合并

入口：插入 → 代码块（先选语言）；代码块右上角复制/换语言。

Callout / Admonition 提示块 S

注意 / 提示 / 重要 / 警告 / 危险五种，支持 GitHub Alerts 语法；和暖纸主题统一配色。

自研语法 + CSS渲染与阅读共用

入口：插入 → 提示块；选中引用块后可一键转成 Callout。

目录块 [toc] S

在正文里插入随标题更新的目录，和侧栏大纲共用一份解析结果。

Vditor 支持 / 自研入口移动端也受益

入口：插入 → 目录；手机上也可从「格式」面板直接插入。

脚注 S

自动编号、文末定义、点击跳转；适合引用来源和补充说明。

GFM 渲染可用入口 + 自动编号

入口：插入 → 脚注；选中文字时可直接把选中内容变成脚注。

图片增强 M

宽度 25/50/75/100%、对齐、图注、画廊、点击灯箱（现有 ImageViewer 可复用）。

自研渲染扩展阅读态同步

入口：选中图片 → 图片工具条；插入图片时默认给 100% 宽 + 可选图注。

附件卡片 S

文件链接渲染成带图标、大小、下载按钮的卡片，而不是一行裸链接；复用现有文件上传。

自研渲染与插入文件合并

入口：插入 → 文件（已有）；重点是阅读态的卡片样式。

视频 / 音频嵌入 M

本地视频/音频、或外部链接的播放器块；手机上要考虑流量与自动播放策略。

自研媒体资产已有基础

入口：插入 → 媒体；先做本地文件，外部链接按需。

查找 / 替换 M

页内查找、大小写/正则可选项、全部替换；只作用于当前正文。

自研桌面/手机共用

入口：Ctrl+F / 手机「更多」；与 AI 改写分开，不做语义替换。

分栏预览 M

左侧源码、右侧渲染；窄屏自动收起，阅读态仍走沉浸阅读。

Vditor 预览能力布局工作量为主

入口：编辑模式下拉增加「分栏」；可作为桌面专属，手机不做。

斜杠命令面板 / L

输入 / 弹出「标题 / 表格 / 图表 / 公式 / 画板 / AI」搜索面板，能从根上缓解工具栏膨胀。

自研与插入面板共用动作

入口：正文行首输入 /；键盘 ↑↓ + Enter，手机点选。

块拖拽手柄 L

悬停段落/图片/表格出现手柄：上移、下移、复制、删除、转成其他块。

自研与 Vditor DOM 深度耦合

入口：块左侧 hover；手机长按块。

打字机 / 专注模式 S

当前行居中、其余淡出；写长文时减少视觉噪音。

自研纯 CSS/滚动

入口：全屏编辑里的显示选项；手机不做或放进「格式」。

导出 PDF / HTML / 图片 M

把当前页导出成可分享的文件；需要处理图片、双链、图表渲染的离线资源。

自研 / 服务端渲染图表要等渲染完成

入口：页头「⋯」或状态栏；先做 HTML，PDF 次之。

表格转图表 M

选中一张 Markdown 表格，按列生成 ECharts 柱状/折线图；数据与图保持弱关联。

ECharts 已随包解析 + 表单

入口：表格浮条「更多」→ 生成图表；生成后是独立代码块，不自动同步。

白板页面类型 L

整页就是一块无限画布，适合头脑风暴；和「页面内画板」是两种产品形态，建议后做。

需自研页面类型导航/搜索/同步都要接

入口：新建页面时选「白板」；先不要和 Markdown 编辑器混在一起。
